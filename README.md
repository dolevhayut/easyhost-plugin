# EasyHost plugin for Claude

Marketplace repository for the EasyHost (אירוח בקליק) plugin. The plugin itself is in [`plugins/easyhost`](plugins/easyhost): read its README for what it does and how to connect.

```
/plugin marketplace add dolevhayut/easyhost-plugin
/plugin install easyhost@easyhost
```

This repository holds only the plugin bundle: a manifest, skills and a logo. The EasyHost app and its MCP server are not here.
